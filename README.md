# 🏥 Sistema de Chamada para Clínica com Voz

Este é um projeto em Python desenvolvido para gerir filas de espera em clínicas, com um painel de chamada que utiliza síntese de voz (TTS).

## ✨ Funcionalidades
- **Cadastro de Pacientes:** Registo de nome, CPF e data de nascimento.
- **Gestão de Fila:** Organização automática por ordem de chegada.
- **Painel com Voz:** Chamada sonora do paciente indicando o consultório (voz lenta e clara).
- **Histórico:** Lista de pacientes que já foram atendidos.

## 🚀 Tecnologias Utilizadas
- Python 3
- Biblioteca `pyttsx3` (Text-to-Speech)
